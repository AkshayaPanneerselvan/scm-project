# Student Task Management System

## 1. Project Name
Student Task Management System

## 2. Project Description
The Student Task Management System is a simple web-based application developed to help students organize and manage their academic tasks.

## 4. Project Objectives

- Help students organize their academic tasks.
- Allow students to add new tasks.
- Display the list of tasks.
- Practise Software Configuration Management.
- Use Git and GitHub for version control and collaboration.

## 5. Main Features

- Add new tasks.
- View the task list.
- Validate empty task inputs.

## 6. Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## 7. Basic Setup Instructions

1. Clone the project repository.
2. Open the StudentTaskManagement folder in VS Code.
3. Navigate to the src folder.
4. Open index.html in a web browser.

## 8. Version Control

Git and GitHub are used to track changes, maintain project history and support team collaboration.
