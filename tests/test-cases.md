# Library Management System – Test Cases

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| TC01 | Add a book with valid details | Book should be added |
| TC02 | Add a book without a title | Error message should appear |
| TC03 | Borrow an available book | Status should change to Borrowed |
| TC04 | Return a borrowed book | Status should change to Available |
| TC05 | Remove a book | Book should be removed |

## Testing Result
The above test cases will be executed to verify the basic functionalities of the Library Management System.
