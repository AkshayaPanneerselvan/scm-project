# Library Management System

## Project Description
The Library Management System is a simple web-based application developed as part of the CSE2552 Software Configuration Management practical.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Main Features
- Add new books.
- View available books.
- Borrow books.
- Return books.
- Remove books.
